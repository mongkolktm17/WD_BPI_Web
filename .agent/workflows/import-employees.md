# วิธีการนำเข้าข้อมูลพนักงานทั้งหมด 133 คน

## ขั้นตอนการนำเข้า:

1. เปิดเว็บเบราว์เซอร์และไปที่ `http://localhost/wdbpi/import_officers.php`

2. ล็อกอินด้วยบัญชี Admin

3. เลือก Role ที่ต้องการกำหนดให้กับพนักงานทุกคน (เช่น "เจ้าหน้าที่ประจำจุด")

4. กำหนดเบอร์โทรศัพท์เริ่มต้น (ค่าเริ่มต้นคือ 0000000000) - สามารถแก้ไขภายหลังได้ใน manage_officers.php

5. วางข้อมูล CSV ทั้งหมดลงในช่อง "ข้อมูล CSV" (คัดลอกข้อมูลทั้งหมดที่ผู้ใช้ให้มา)

6. กดปุ่ม "นำเข้าข้อมูล"

7. ตรวจสอบผลการนำเข้า:
   - ✓ สีเขียว = นำเข้าสำเร็จ
   - สีเหลือง = ข้ามไป (มีข้อมูลอยู่แล้ว)
   - ✗ สีแดง = เกิดข้อผิดพลาด

## หมายเหตุ:

- รหัสพนักงานต้องเป็นตัวเลข 8 หลัก
- ระบบจะตรวจสอบว่ามีรหัสพนักงานหรือชื่อผู้ใช้ซ้ำหรือไม่
- รหัสผ่านจะถูกเข้ารหัสอัตโนมัติด้วย password_hash
- หลังจากนำเข้าแล้ว สามารถแก้ไขข้อมูลแต่ละคนได้ที่ manage_officers.php
