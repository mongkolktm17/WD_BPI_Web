# UAT-01: Auth + Dashboard + การ์ด Admin

- บัญชีที่ใช้: ไม่ login, `admin`, `100001`
- ต้องทำ `00-setup.md` ข้อ 1-4 ก่อน

## ขั้นตอน

| # | ทำ | คาดหวัง |
|---|---|---|
| 1 | ไม่ login เปิด `http://localhost:3000/report-page` ตรง | ดีดไป `/login` |
| 2 | login ผิดรหัส | error ภาษาไทย อยู่หน้าเดิม |
| 3 | login `admin` / `admin123` | เข้า `/` ชื่อ- role ถูกต้อง |
| 4 | ดูตัวเลข 5 กลุ่ม (รปภ. / รถ / มอไซค์ / กล้อง / NVR) | ตรงกับข้อมูลที่ seed (ช่วงแรกอาจเป็น 0 — จดค่าตั้งต้นไว้) |
| 5 | login `100001` เปิด `/admin/users` และ `/admin/settings` ตรง | ถูกพากลับ `/report-page` ทั้งคู่ |
| 6 | กด Logout | กลับ `/login`, กด back ไม่เห็นข้อมูลเดิม |
