# UAT-04: สิทธิ์ดู/แก้/ลบใน Inbox

- บัญชีที่ใช้: `100001` (เจ้าของ) vs `100002` (คนอื่น) vs `admin`

## ขั้นตอน

| # | ทำ | คาดหวัง |
|---|---|---|
| 1 | `100002` เปิดแถวของ `100001` | ดูได้ แต่ไม่มีปุ่มแก้ |
| 2 | `100001` เปิดแถวตัวเอง | มีปุ่มแก้ ไม่มีปุ่มลบ |
| 3 | `100002` เปิดแถวตัวเอง | มีปุ่มแก้ (พิสูจน์ว่าเทียบรหัส ไม่ใช่ชื่อ) |
| 4 | `admin` ลบ 1 แถวทดสอบ | ลบได้, แถวหายจาก list |
| 5 | เทียบ QuickLinks: `admin` vs `100001` | admin เห็น 11 อัน, `100001` เห็นเฉพาะตามสิทธิ์ role |

## เกณฑ์ผ่าน
5/5 ข้อ — ถ้า non-admin เห็นปุ่มลบ = **Critical**
