# UAT Sign-off — เกณฑ์ปิด + แบบฟอร์มบั๊ก

## เกณฑ์ปิด UAT
- UAT-01–12, 14: ข้อ P ผ่าน 100%
- UAT-13: มีตารางเทียบครบ (ไม่ตัดสินที่ตัวเลข)
- บั๊ก Critical (ข้อมูลหาย / ลบผิด / non-admin เข้า admin ได้ / API ข้ามสิทธิ์) = 0 ค้าง

## แบบฟอร์มบันทึกบั๊ก (ใช้ทุกตัว)

```
[UAT-0X] หน้า | บัญชี | ซ้ำ 1-2-3 | คาดหวัง | ที่เกิดจริง | Critical/Major/Minor | ภาพหน้าจอ
```

## ส่งมอบหลังเทส
1. ติ๊กผลในไฟล์ UAT-01–14
2. รวมรายการบั๊กตามฟอร์มข้างบนส่งมา
3. รอบถัดไป: ซ่อมทีเดียวแล้วออก UAT รอบ 2 เฉพาะข้อที่ตก
